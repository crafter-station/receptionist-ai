# Conoce al recepcionista en producción

[Ver la lección](https://learning.crafter.run/courses/whatsapp-ai-receptionist/watch/01-see-the-production-receptionist)

La demostración presenta la experiencia que construiremos: el cliente escribe por WhatsApp, el agente pregunta su nombre, recuerda la conversación y usa Cal.com para consultar horarios y reservar una visita.

```text
Cliente → WhatsApp → Kapso → Hono → AI SDK
                              ↕       ↕
                         Neon/Drizzle Cal.com
```

Todavía no se escribe código en esta lección. Observa el recorrido del cliente antes de conectar la primera API.
